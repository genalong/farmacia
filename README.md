# Sitio web para Farmacia 

Sitio web desarrollado como proyecto de práctica para una farmacia ubicada en Juan Lacaze, Uruguay.

##  Herramientas usadas

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js

##  Cráneo principal del contenido

- Página principal
- Catálogo de productos
- Buscador de productos
- Filtro por categoría
- Carrito de compras
- Modificación de cantidades
- Eliminación de productos
- Formulario de pedidos
- Diseño responsive
- Comunicación entre frontend y backend mediante API REST

##  Carrito

Los productos agregados al carrito se almacenan utilizando `localStorage`.

##  Backend

El proyecto cuenta con un pequeño backend desarrollado con Node.js y Express.js.

Actualmente permite:

- Obtener productos mediante `GET /api/productos`
- Recibir pedidos mediante `POST /api/pedidos`
